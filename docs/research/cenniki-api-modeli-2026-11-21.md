# Cenniki API modeli tekstowych – Web Search, Batch i Responses

**Stan na 21 listopada 2026.** Porównanie obejmuje publiczne API modeli tekstowych, platformy udostępniające modele wielu producentów i osobne wyszukiwarki. Tabele zawierają stawki wybranych modeli oraz linki do pełnych katalogów poszczególnych usług. Katalogi pokazują zakres danego dostawcy, a dostępność może zależeć od regionu i konta. Dane pochodzą z dokumentacji i cenników. Kombinacji funkcji nie sprawdzano płatnymi wywołaniami.

## Kiedy można połączyć Batch z wyszukiwaniem

**Web Search** to wyszukanie aktualnych źródeł podczas generowania odpowiedzi. **Batch API** przyjmuje paczkę niezależnych zleceń i zwraca wyniki po ich przetworzeniu. **Responses API** oznacza interfejs `POST /v1/responses` lub jawnie opisany zgodny odpowiednik. Własne interfejsy Claude i Gemini też zwracają odpowiedzi z narzędziami, ale wymagają innego formatu.

| Usługa | Responses lub interfejs dostawcy | Wyszukiwanie w zadaniu Batch | Źródła |
| --- | --- | --- | --- |
| xAI Grok | `/v1/responses` | **Tak**, dokumentacja pokazuje `grok-4.3` z `web_search` w pliku Batch dla Responses. | [Batch](https://docs.x.ai/developers/advanced-api-usage/batch-api) |
| Perplexity Agent API | `/v1/responses` jest aliasem `/v1/agent` | **Tak**, oficjalny przykład używa `/v1/responses` w Batch z `web_search` i `fetch_url`. | [Zgodność z Responses](https://docs.perplexity.ai/docs/agent-api/openai-compatibility), [Batch](https://docs.perplexity.ai/docs/agent-api/batch), [przykład wyszukiwania informacji o firmach](https://docs.perplexity.ai/docs/cookbook/examples/batch-api-company-enrichment/README) |
| Anthropic Claude | `/v1/messages` | **Tak**, narzędzie Claude działa w Message Batches. Stawka za samo wyszukiwanie pozostaje standardowa. | [Web Search w Batch](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool#batch-requests) |
| Google Gemini Developer API | `generateContent` i Interactions API | **Udokumentowane dla Batch GenerateContent**, np. dla Gemini 3.x. Batch jest dostępny wyłącznie z GenerateContent. Dla Gemini 4 osobno potwierdzono narzędzie i Batch, bez jednoznacznego rozliczenia kombinacji w tabelach Batch. | [Batch](https://aistudio.google.com/docs/batch-api), [cennik](https://aistudio.google.com/docs/pricing) |
| OpenRouter | `/api/v1/responses` | **Tak**, zależnie od modelu, dostawcy i endpointu. Dokumentacja wprost wskazuje narzędzie OpenAI dla Responses i narzędzie Claude dla Messages. Własna wyszukiwarka OpenRouter działa poza Batch. | [Batch Quickstart](https://openrouter.ai/docs/batch-quickstart) |
| OpenAI bezpośrednio | `/v1/responses` | **Do potwierdzenia**. Batch oficjalnie obsługuje Responses, a Responses ma `web_search`. Dokumentacja OpenAI opisuje wspólny format parametrów, ale brakuje w niej przykładu potwierdzającego wykonanie wyszukiwania w Batch. Wyszukiwanie w pojedynczym żądaniu Responses w trybie `background` jest opisane wprost. | [Batch](https://developers.openai.com/api/docs/guides/batch), [Web Search](https://developers.openai.com/api/docs/guides/tools-web-search), [Background](https://developers.openai.com/api/docs/guides/background) |

## Wniosek

Jeśli aplikacja wymaga wbudowanego wyszukiwania w Batch na `/v1/responses`, dokumentacja zawiera bezpośrednie przykłady w xAI i Perplexity. OpenRouter opisuje tę konfigurację dla natywnego narzędzia OpenAI. Claude i Gemini dokumentują Batch z wyszukiwaniem we własnych interfejsach. Przy krótkich analizach sam rabat Batch może mieć niewielki wpływ na całkowitą cenę, ponieważ opłata za wyszukiwanie jest często większa od stawki za generację.
