## When we return to the questions

Not all items need to be closed before the first implementation. When taking up a specific feature, we pick the questions that concern it and refine its requirements/solution design against the current state of the application. The owner's earlier answers still apply; proposals do not become decisions just by being left in the draft. Configuration values and measurements still require verification before use, but they are not a mandatory global interview at this stage.

Before code we return to the documentation of the chosen piece. Adopting this cycle does not by itself start implementation or authorise purchases/deployment. [Full work cycle](README.md#feature-work-cycle).
