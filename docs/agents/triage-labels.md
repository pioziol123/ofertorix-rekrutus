# Triage labels

These labels classify project issues, independently of job-offer triage.

| Role | Beads label | Meaning |
| --- | --- | --- |
| Needs evaluation | needs-triage | Requires evaluation |
| Missing information | needs-info | Requires more information |
| Agent-ready | ready-for-agent | Specified and ready for an agent |
| Human-ready | ready-for-human | Requires human implementation |
| Declined | wontfix | Will not be implemented |

Labels complement Beads statuses; they do not replace them.
